# ВЫПУСКНАЯ КВАЛИФИКАЦИОННАЯ РАБОТА  
**Разработка микросервисного приложения для интеграции с распределенными хранилищами данных**

## Описание проекта
Данная работа посвящена разработке приложения, которое упрощает и ускоряет создание программных продуктов, работающих с различными распределенными хранилищами данных:

- Полнотекстовое хранилище
- Распределенная файловая система
- База данных временных рядов

### Ключевые результаты
- Проведен анализ аналогов системы
- Выбраны оптимальные хранилища данных
- Сформулированы требования к приложению
- Разработана архитектура решения
- Реализован и протестирован программный код
- Продемонстрировано применение в библиотеке приложений

## Актуальность
Решение позволяет сократить:
- Затраты человеческих ресурсов на разработку интеграций
- Время поддержки стороннего ПО

## Технологический стек
- **Язык программирования**: Java 17
- **Сборка**: Apache Maven
- **IDE**: IntelliJ IDEA
- **Основной фреймворк**: Spring Framework
- **Интеграции**: Apache SOLR, Apache HDFS, InfluxDB
- **Дополнительные технологии**: Apache Zookeeper, Apache Kafka, PostgreSQL

## Структура репозитория

### Основные сервисы
1. `administration_service` - сервис администрирования
2. `archive_service` - сервис архивных задач
3. `data-management-service` - сервис обработки данных
4. `fulltext_service` - сервис полнотекстовых задач
5. `monitoring_service` - сервис задач мониторинга
6. `user-api-service` - сервис пользовательского API

### Вспомогательные модули
- `client-dtos` - общие DTO сущности
- `common-entities` - общие сущности БД
- `common-starter` - общие настройки сервисов
- `data-generator` - генератор тестовых метрик
- `library-application` - демонстрационный модуль
- `mds-system-client` - клиентская библиотека

### Конфигурационные файлы
- `solr/` - политика security для Solr
- `docker-compose.yaml` - настройки Docker
- `hadoop.env` - конфигурация HDFS
- `managed-schema.xml` - схема данных Solr

## Запуск приложения (Docker)

1. Запустите стороннее ПО:
   ```bash
   docker-compose up
   ```
2. Запустите сервисы с профилем docker в указанном порядке:
- administration_service
- fulltext_service
- monitoring_service
- archive_service
- data-management-service
- user-api-service

Примечание: Для отключения конкретных задач установите соответствующие параметры в false в сервисе обработки данных:

mds.archive.enabled
mds.monitoring.enabled
mds.fulltext.enabled
